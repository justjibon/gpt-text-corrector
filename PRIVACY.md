# Privacy

GPT Text Corrector does not operate a project-owned server.

When a user requests an AI action, the selected text is sent directly from the browser extension to the OpenAI API using the user's configured API key.

The extension stores the API key and preferences locally using Chrome extension storage.

Users should avoid sending sensitive or confidential information unless they are comfortable with the applicable terms and privacy practices of their selected AI provider.

The project does not include a shared API key.
